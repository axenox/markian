# Runnable Examples

Serve this package directory with any static HTTP server, then open [the minimal editor](index.html). It loads only the prebuilt core script and stylesheet. No framework, external service, remote font, npm install, or consumer build is required.

The [source](minimal.js) mounts a textarea, subscribes to changes, shows its form value, and supports native reset and destruction. The checkout's root workspace additionally demonstrates two themes, read-only editing, and the optional Code slice through [demo.js](demo.js). Its root HTML page is a checkout-only development asset; the minimal example is included in npm/Composer archives.

These are early W1-W3 examples. Provider services, Mermaid, advanced editing controls, and the standalone viewer are not implemented here.

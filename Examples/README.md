# Runnable Examples

Serve this package directory with any static HTTP server, then open [the minimal editor](index.html). It loads only the prebuilt core script and stylesheet. No framework, external service, remote font, npm install, or consumer build is required.

The [source](minimal.js) mounts a textarea, subscribes to changes, shows its form value, and supports native reset and destruction. The checkout's root workspace additionally demonstrates two themes, read-only editing, and the optional Code slice through [demo.js](demo.js). Its root HTML page is a checkout-only development asset; the minimal example is included in npm/Composer archives.

The [Mermaid example](mermaid.html) separately registers and enables the optional W13 factory and stylesheet in [mermaid.js](mermaid.js). The host supplies the Mermaid URL/version through [mermaid.config.js](mermaid.config.js). `npm run dev` serves the development-only Mermaid 12.2.0 dependency at `/host-assets/mermaid.min.js`; this renderer is not included in the package. For static hosting, supply that route yourself or update the config file to a trusted supported Mermaid URL. Missing configuration or loading failures display an error without losing fenced source. The example demonstrates centered labels, floating diagram controls, multiple diagrams, per-editor themes, read-only inspection, and the dedicated code/preview workspace. The minimal example and default workspace remain unchanged and do not request Mermaid. Both examples are included in npm/Composer archives.

Provider services, host integrations, and the standalone viewer are not implemented by these examples. See the [API and renderer contract](../README.md#optional-mermaid-extension) for supported versions, safety limits, loading, and remaining device/CSP gates.

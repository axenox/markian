# Runnable Examples

Serve this package directory with any static HTTP server, then open [the example index](index.html). No framework, external service, remote font, npm install, or consumer build is required for the core editor/viewer examples. A development checkout can use `npm run dev -- --port 5195 --strictPort`; consumers use the committed prebuilt assets.

The [minimal editor](minimal-editor.html) mounts a textarea, subscribes to changes, shows its form value, and supports native reset and destruction. The [editor workspace](editor-workspace.html) demonstrates two themes, read-only editing, and the optional Code slice. Each named HTML file keeps its configuration and script inline; [demo.css](demo.css) supplies the shared page shell. The examples are included in npm/Composer archives.

The [Mermaid example](mermaid-diagrams.html) separately registers and enables the optional W13 factory and stylesheet. Its inline host configuration supplies the Mermaid URL/version. `npm run dev` serves the development-only Mermaid 12.2.0 dependency at `/host-assets/mermaid.min.js`; this renderer is not included in the package. For static hosting, supply that route yourself or update the host configuration to a trusted supported Mermaid URL. Missing configuration or loading failures display an error without losing fenced source. The example demonstrates centered labels, floating diagram controls, multiple diagrams, per-editor themes, read-only inspection, and the dedicated code/preview workspace. The minimal example and default workspace do not request Mermaid.

The [editor/viewer comparison](viewer.html) shows equal desktop panes, stacked on narrow screens. Editor changes update the viewer with the same Markdown; theme changes, document replacement, and destruction affect both. This comparison intentionally loads both bundles, while standalone viewer hosts need only the viewer script/CSS. Tasks remain interactive only in the editor. `mermaid: false` prevents rendering/runtime loading even for its Mermaid fence. To opt in, use the separate [viewer adapter contract](../README.md#optional-viewer-rendering), not the W13 editing extension. The example works from subdirectory asset routes without a build or remote dependencies.

Provider services and host widget integrations are not implemented by these examples. See the [editor renderer contract](../README.md#optional-mermaid-extension) and [viewer guide](../README.md#lightweight-viewer) for supported versions, safety limits, measurements, and remaining device/CSP gates.
